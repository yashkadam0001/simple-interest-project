# Simple Interest Calculator

This project calculates simple interest based on the principal amount, annual rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

- **Principal:** The initial amount of money.
- **Rate:** The annual rate of interest in percentage.
- **Time:** The time period in years.

## Example

If the principal is 1000, the rate is 5%, and the time period is 2 years:

Simple Interest = (1000 × 5 × 2) / 100 = 100

Therefore, the simple interest is 100.

## Purpose

This project demonstrates the calculation of simple interest using a simple formula.
